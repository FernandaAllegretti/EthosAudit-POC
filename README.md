## 🚀 Sobre o Projeto
O EthosAudit é uma solução inteligente em Python estruturada para auditar evoluções clínicas e prontuários de saúde. O objetivo principal é mitigar o risco de conformidade ética, identificando termos altamente subjetivos, vieses cognitivos e julgamentos de valor que possam comprometer a integridade técnica do documento médico/psicológico.

## 📊 Funcionalidades Desta Versão (PoC)
* Varredura léxica básica por expressões regulares (`re`).
* Identificação de termos de julgamento comuns.
* Emissão de relatório simplificado em formato JSON com diretrizes de correção.

## 🛠️ Tecnologias Utilizadas
* Python 3.10+
* Expressões Regulares Avançadas (Regex)
